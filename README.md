# 四則計算ドリル

ブラウザだけで遊べる、シンプルな四則計算ドリルです。

足し算・引き算・かけ算・割り算からランダムに10問が出題されます。回答後に正誤を確認でき、10問終了後には得点・正答率・全回答の振り返りが表示されます。

## 主な機能

- 足し算・引き算・かけ算・割り算をランダムに出題
- 1セット10問
- 回答直後に正誤を表示
  - 正解：`正解！`
  - 不正解：`不正解。正解は○です。`
- 正誤を確認してから次の問題へ進む形式
- 10問終了後に得点と正答率を表示
- 全10問の回答履歴を表示
  - 出題された計算式
  - 入力した答え
  - 正しい答え
  - 正解・不正解
  - 不正解だった場合の計算方法と、正解との差
- 「もう一度挑戦する」で最初から再開
- PC・タブレット・スマートフォンに対応したレスポンシブデザイン
- Enterキーによる回答に対応

## 出題ルール

| 種類 | 記号 | ルール |
| --- | --- | --- |
| 足し算 | `＋` | 1〜10の整数同士を足します |
| 引き算 | `−` | 答えがマイナスにならないよう、大きい数から小さい数を引きます |
| かけ算 | `×` | 1〜10の整数同士をかけます |
| 割り算 | `÷` | 必ず割り切れる問題が出題され、答えは1〜10になります |

割り算では余りや小数が発生する問題は出題されません。割られる数は最大100です。

## 遊び方

1. 表示された問題の答えを入力します。
2. **「答える」** ボタンを押します。Enterキーでも回答できます。
3. 問題の下に表示される正誤を確認します。
4. **「次の問題」** を押して次へ進みます。
5. 10問目の正誤を確認したら、**「結果を見る」** を押します。
6. 得点、正答率、全問題の回答履歴を確認します。

採点対象になるのは、各問題で確定した1回の回答です。回答後に入力内容を変更することはできません。

## 実行方法

このアプリは単一のHTMLファイルで動作し、インストールやビルドは不要です。

### ダウンロードして開く

1. このリポジトリの **Code** → **Download ZIP** を選択します。
2. ダウンロードしたZIPファイルを展開します。
3. [`ArithmeticDrill.html`](./ArithmeticDrill.html) をダブルクリックしてブラウザで開きます。

### Gitを使用する

```bash
git clone https://github.com/cozy51/2028-08_ArithmeticDrill.git
cd 2028-08_ArithmeticDrill
```

その後、`ArithmeticDrill.html` をブラウザで開いてください。

> [!NOTE]
> 現在、GitHub Pagesは設定されていません。GitHub上で直接プレイするのではなく、HTMLファイルをダウンロードして開いてください。

## 結果と振り返り

結果画面では、10問中の正解数と正答率に加えて、すべての回答を確認できます。

不正解の場合は、次のような説明が表示されます。

```text
7から4を引くと3です。あなたの答えは正解より1小さくなっています。
```

```text
42を7で割ると6です。あなたの答えは正解より2大きくなっています。
```

PCやタブレットでは回答履歴を複数列で表示し、縦方向のスクロールを抑えています。スマートフォンでは読みやすさを優先して1列で表示します。
